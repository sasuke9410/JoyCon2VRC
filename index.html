🏗️ システムアーキテクチャ & 基本仕様

本システムは、左太ももに固定した任天堂SwitchのJoy-Con (L) 内蔵6軸センサー (加速度3軸 + ジャイロ3軸) を用いて、 ユーザーの「その場足踏み」および「膝の曲げ伸ばし動作」をリアルタイム解析し、VRChat空間内の移動入力へ変換します。

🎯 対応動作パターン

  • 通常足踏み（歩き）: 適度な足上げと着地衝撃 → 低速前進
  • 通常足踏み（走り）: 高速足踏み (140+ SPM) → 高速前進
  • サイレント歩き/走り: かかとを着地したまま膝の素早い曲げ伸ばしで階下静音移動

⚡ 低遅延 & 安定性

  • WebHID / Direct HID により 応答遅延 < 20ms を実現
  • 相補フィルタ (Complementary Filter) によりセンサーノイズとドリフトを吸収
  • ヒステリシス閾値処理による誤判定・チャタリング防止

🧮 歩行検出アルゴリズムの詳細

1. 通常足踏みモード (Impact & Cadence Algorithm)

太ももの上昇・下降による着地インパクト A_dyn と、ステップ間隔から算出されるピッチ (SPM) をトリガーとします。

// 合成動的加速度の計算 (重力成分除去) double A_total = sqrt(Ax*Ax + Ay*Ay + Az*Az); double A_dyn = abs(A_total - 1.0); // 1.0G (重力) の差分 // ステップピーク検出 if (A_dyn > Threshold_Step && (currentTime - lastStepTime) > Min_Step_Interval) { double dt = currentTime - lastStepTime; double SPM = 60.0 / dt; // 1分あたりの足踏み数 lastStepTime = currentTime; if (SPM >= Run_SPM_Threshold) { state = STATE_RUN; // OSC Vertical = 1.0 } else { state = STATE_WALK; // OSC Vertical = 0.5 } }

2. サイレントモード (Knee Pitch Angle Algorithm)

床に着地衝撃を与えないよう、かかとを浮かせず膝を前後に曲げ伸ばしする動作を検出します。太ももの傾き角 (Pitch) の極大値・極小値をセンシングします。

// 相補フィルタによる太もものピッチ角 (傾き) 推定 double accelPitch = atan2(Ax, Az) * (180.0 / M_PI); pitchAngle = 0.95 * (pitchAngle + GyroY * dt) + 0.05 * accelPitch; // 膝曲げ運動の往復振幅 (Amplitude) 算出 double deltaAngle = abs(currentPitch - baselinePitch); if (deltaAngle > Silent_Angle_Threshold) { // 連続運動カウント更新 activeMotionTimer = 0.5; // 0.5秒間移動状態を維持 // 曲げ伸ばしの角速度により walk / run 判定 if (abs(GyroY) > Silent_Run_Gyro_Threshold) { state = STATE_RUN; } else { state = STATE_WALK; } }

🌐 VRChat OSC / 仮想キー設定ガイド

1. Wキー仮想入力方式 (簡易設定)

キーボードの `W` キー入力をシミュレートする方式です。ゲーム内設定を変更せずに動作します。

  • Walk: WキーをON (または一定間隔でパルス送信)
  • Run: Shift + WキーをON

2. VRChat Native OSC方式 (推奨・高度設定)

VRChat標準のOSC Input機能を利用します。アナログスティックのように滑らかな速度調節が可能です。

  • 送信先アドレス: `127.0.0.1 : 9010` (UDP)
  • 前進アナログ入力: `/input/Vertical` (Float: `0.0` ~ `1.0`)
  • ダッシュフラグ: `/input/Run` (Int: `0` または `1`)

🐍 Python OSC/Wキー ブリッジスクリプト例

本WebアプリまたはローカルPythonスクリプトからVRChatへOSCメッセージを送信する最小コード例です。

import time from pythonosc import udp_client # VRChatデフォルトOSCポート client = udp_client.SimpleUDPClient("127.0.0.1", 9010) def send_vrchat_movement(speed: float, is_running: bool): """ speed: 0.0 (停止), 0.5 (歩き), 1.0 (走り) """ client.send_message("/input/Vertical", speed) client.send_message("/input/Run", 1 if is_running else 0) # 例: 歩行中 send_vrchat_movement(0.5, False)
