# JoyCon2VRC - Joy-Con(L) ロコモーション コントローラー

[English Edition (英語版はこちら)](README.en.md)

---

Nintendo Switchの **Joy-Con (L)** のモーションセンサーを活用し、脚部のステップ動作によって VRChat 内を直感的に移動（歩行・走行）させるデスクトップアプリケーションです。

---

## ⚡ クイックスタート (EXE版の使い方)

PCにPython環境等がなくても、ビルド済みの `.exe` ファイルのみで今すぐ使用できます。

1. **Joy-Conの準備**
   * Windowsの「設定」 -> 「Bluetooth とデバイス」から、Joy-Con (L) をペアリングします。
2. **アプリの起動**
   * [**dist/JoyCon2VRC.exe**](file:///c:/Users/sasuke/Documents/Joycon2VRC/dist/JoyCon2VRC.exe) をダブルクリックして起動します。ペアリング済みのJoy-Conがバックグラウンドで自動検出・接続されます（ステータスが「Joy-Con(L) 接続中」になります）。
3. **キャリブレーション（初回推奨）**
   * 画面上の「キャリブレーション」をクリックし、画面内のカウントダウン表示に合わせて、**静止（3秒）** -> **歩行（5秒）** -> **走行（5秒）** を行います。
4. **VRChat側の設定**
   * VRChat内で `R` キー長押し（アクションメニュー） -> `Options` -> `OSC` -> **`Enabled: True`** に設定します。
5. **連動開始**
   * アプリ画面の「VRChat連携: OFF」をクリックして **`ON`** に切り替えます。足踏みを行うとアバターが移動します。

## ✨ 主な機能 (v1.1のアップデート)

* **静止中の誤移動（STOPドリフト）の防止**:
  * 1歩目の時点では移動コマンドを保留する「**2-Step確定ゲート**（READY状態）」および、ジャイロセンサーでの太もも振り出し角速度（$G_y$ / $G_x$）検証を採用。立ち止まった状態で片足に体重を乗せ替えたり、足首を揺らした程度の単発の衝撃による誤移動を確実に防止します。
* **動的アナログ速度制御（Dynamic Speed）**:
  * 足踏みのピッチ（SPM）および踏み込みの衝撃強度（$A_{dyn}$）から、移動入力強度を `0.25` から `0.95` までの範囲でリアルタイムに計算し、しきい値を超えると `1.0` (RUN) になめらかに移行します。GUI上のボタンで「動的」と「固定値 (0.5/1.0)」をいつでも切り替えられます。
* **オートスリープ回避（キープアライブ処理）**:
  * バックグラウンド処理にて、15秒おきにPlayer 1 LED点灯設定コマンド（サブコマンド `0x30`）をJoy-Conに送信して生存通知を行い、立ち止まり中もJoy-Conが自動スリープに入るのを防止します。
* **電池残量および接続安定性の「数値（％）」表示**:
  * 電池残量を `100%`, `70%`, `30%`, `10%`, `0%` のパーセンテージで表示。
  * 接続安定性をパケット到着率（目標60Hz）とジッターから算出してリアルタイムにパーセンテージ表示。チラつき防止のため、1秒に1回のペースで滑らかに数値が更新されます。
* **外れ値トリム（Trimmed Mean）キャリブレーション**:
  * 測定5秒間における「動き始めの立ち上がり」と「終了時の脱力・減速」を自動でカットするトリム平均を適用し、より信頼性の高い個人設定値が自動生成されます。
* **設定の永続化保存**:
  * キャリブレーションで決定されたパラメータや、スライダー手動調整値、速度モードが `localStorage` へ自動でセーブされ、次回起動時にもそのまま復元・適用されます。
* **自動クリーンアップ（停止フック）**:
  * アプリの `X` ボタンでの終了時や強制終了時に、VRChat側のアバターが走り続けてしまうのを防ぐため、停止信号（0.0）を自動で連打送信して安全に終了します。

## 動作環境

* **OS**: Windows 10 / 11 (Bluetooth機能必須)
* **機器**: Nintendo Switch Joy-Con (L)
* **固定具**: 脚部にJoy-Conを固定するバンド等
* **対象アプリ**: VRChat (PC版 / VR版)

## 🐍 開発者向け起動方法

ソースコードから実行・開発する場合は以下をご使用ください。

```powershell
# 依存関係のセットアップ (uv環境推奨)
uv sync

# アプリケーションの起動
uv run python main.py

# 自動テストの実行
uv run pytest test_system_automated.py
```
