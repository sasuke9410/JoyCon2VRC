JoyCon2VRC 判定改善＆動的速度制御 実装計画書

静止時（重心移動等）の誤歩行判定の根本原因分析と解消、およびIMUセンサ値（ケイデンス＋動的衝撃加速度）によるVRChat OSC動的速度制御の技術仕様と移行ロードマップ

01 課題1：STOP中の重心移動による誤WALK判定の原因調査と解決策

発生している現象と根本原因

  • 現象：静止時に片足に体重を移動させたり足首を揺らした際、意図せずWALK判定となりアバターが前進する。
  • 原因①（単発スパイクでの即時発火）：現状のロジックでは、dynAccel > sensThreshold（0.35G）を1度でも超えると、直ちに cooldownUntil = now + activeHold（1100ms）がセットされ、1歩目でWALK状態に突入する。
  • 原因②（周期性の未検証）：体重移動による「単発の加速度変化」と、連続歩行による「リズミカルな振動波形」を区別していない。
  • 原因③（太ももスイング角の無視）：足踏み時は大腿のピッチ角や角速度（Gy）が大きく振れるが、重心移動ではピッチ角スイングが微小である点を判定に利用していない。

多層フィルタによる解決策

  • 多層判定① 2-Step確定ゲート（Cadence Trigger）： 初回の閾値超過（1歩目）は「予備状態（PENDING）」とし、有効周期内（200ms〜900ms）に2歩目の衝撃またはスイングが検知されて初めて WALK 状態を出力。単発衝撃は無視。
  • 多層判定② ピッチ角・ジャイロ連動フィルタ： 単なる全軸加速度 $A_{dyn}$ だけでなく、大腿部の前後スイング角速度 $|G_y|$ または $\Delta Pitch$ が閾値以上（例: >10°/s）変化している場合のみ有効ステップとみなす。
  • 多層判定③ 自動ゼロ点・ベースライン適応： 静止中の微小な傾き変化をベースラインとして学習し、姿勢変更を誤検知しない。

アルゴリズム比較：判定ロジックの刷新

// 【従来の判定（単発スパイクで即WALK発動してしまっていた）】
if (dynAccel > sensThreshold) {
    cooldownUntil = now + 1100; // 1回の重心移動で即座に1.1秒間歩行モードになる！
}

// 【新しい高精度多層判定（2-Step Gate + Gyro Verification）】
const isSwingActive = Math.abs(rawGy) > gyroThreshold; // 太もものスイング角速度検証
if (dynAccel > sensThreshold && isSwingActive) {
    const dt = now - lastStepTime;
    if (dt >= 200 && dt <= 950) {
        stepCount++;
        if (stepCount >= 2) {
            // 2歩以上の連続リズムを確認して初めて歩行確定
            stateName = 'WALK';
            cooldownUntil = now + holdTimeMs;
        }
        lastStepTime = now;
    } else if (dt > 950) {
        stepCount = 1; // 単発（重心移動など）はカウント1の保留状態とし、移動出力はしない
        lastStepTime = now;
    }
}
02 課題2：センサ値からの動的速度推定とOSCアナログ送信設計

従来は WALK = 0.5 / RUN = 1.0 の固定値2値制御でした。 足踏みのテンポ（SPM）および衝撃強度（$A_{dyn}$ / ピッチ角速度）から疑似的な歩行速度をリアルタイム算出し、VRChat の /input/Vertical へ 0.15 〜 1.00 の連続的なアナログ浮動小数点数を動的送信します。

1

ケイデンス速度要素 ($V_{spm}$) の算出

ステップ間隔 $\Delta t$ からリアルタイムSPM（歩/分）を計算し、基準レンジ（例: 70〜190 SPM）を 0.15〜1.0 に正規化。

const normalizedSpm = Math.min(Math.max((smoothedSpm - 70) / (190 - 70), 0.0), 1.0);
const vSpm = 0.2 + 0.8 * normalizedSpm; // 0.20 〜 1.00
2

衝撃・歩幅強度要素 ($V_{intensity}$) の重み付け合成

足踏みの強さ（$A_{dyn}$ ピーク値）や大腿の上げ具合（$G_y$ 角速度）を速度係数に乗算し、ゆっくり小股足踏みなら遅く、大きく力強い足踏みなら素早く加速。

const intensityFactor = Math.min(Math.max(peakAdyn / sensThreshold, 0.8), 1.3);
const rawTargetSpeed = Math.min(Math.max(vSpm * intensityFactor, 0.15), 1.0);
3

スルーレートリミッター（EMA / 加減速スムージング）

OSC値の急激なガタつきを防ぎ、アバターが自然に加速・減速するように 1次遅れフィルタを適用。

currentSpeed = currentSpeed * (1.0 - alpha) + targetSpeed * alpha; // alpha = 0.15
